À propos du MVPT-4

Ce calculateur implémente les tables officielles du Motor-Free Visual Perception Test, 4e édition.

Tables utilisées : B.1 (score brut → score standard), B.2 (score standard → percentile, NCE, T-score, score scalé, stanine), B.3 (équivalents d'âge).

Les sessions sont sauvegardées dans une base SQLite sur le serveur.
